# Cronograma

Cinco módulos: fundamentos (1), Python (2–3), reprodutibilidade e paradigmas didáticos (4–7), modelos de mudança da terra no DisSLUCC, com dados e cenários (8–12), e projeto (13–15). No bloco de LUCC o modelo vem antes dos dados: o aluno roda um modelo com dados prontos (9) e só então monta, com o DisSCube, variáveis do tipo das que o potencial usa (10). A verificação contra o TerraME e o LuccME não tem aula própria: aparece em cada encontro em que um modelo do DisSModel é apresentado ao lado do original (5, 6, 7 e 9). O projeto final começa a ser definido no encontro 7, para haver tempo de montar os dados.
